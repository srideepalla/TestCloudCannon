title: Search Past Winners
description: 'Searchable, filterable directory of past Stevie Award winners.'
overview: 'A live search section backed by the Search Past Winners API. Visitors can search by keyword or plain question ("who won gold in 2024", "IBM", "top 10 companies by number of wins"), narrow by award level, country, industry and year range, and page through results. With no query it opens on the full record list, so it doubles as a browsable directory. The optional summary panel above the results reports totals, award-level counts and top organizations counted across every match, not just the visible page. Because the site builds static, the search runs in the browser against the API, so the component needs the API to be reachable from the visitor — set apiEndpoint to a public URL, not localhost, before publishing.'
