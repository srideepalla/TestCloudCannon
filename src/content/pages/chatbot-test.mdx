Temporary page for testing the `StevieChatbot` component against the StevieIntel
chatbot API. Delete this page before merging to a release branch.

The chatbot is added through **Page Sections** above rather than written into this
body. That matters for CloudCannon: a section's values live in the page's
front matter, which is what the component's `data-prop` bindings point at. Used
inline in the body it has no such path, and the visual editor reports
"Failed to render text editable region ... received a value of type 'undefined'".
